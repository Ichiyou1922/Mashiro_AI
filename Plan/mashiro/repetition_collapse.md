# 📝 LLM会話崩壊現象まとめ

3B（30億パラメータ）クラスの小型モデルで、特に日本語会話を行う際に発生しやすい現象の分類と原因です。

## 1. 反復崩壊 (Repetition Collapse)

**現象:**
同じ単語やフレーズを無限に繰り返す。
例：「ましろましろましろ...」「テキストテキストテキスト...」

**原因:**

* **確率の自己強化ループ**: LLMは「次に来る確率が最も高い単語」を選びます。一度「ましろ」と言った後、文脈によっては次も「ましろ」が来る確率が高まることがあります（例：名前を連呼する場合など）。
* **局所解へのハマり**: 2回繰り返すと、3回目もその単語が来る確率が幾何級数的に跳ね上がり、他の単語の確率がほぼ0になり、抜け出せなくなります。

**対策:**

* `frequency_penalty` (頻度ペナルティ) を上げる。
* `max_tokens` (発言長) を制限して強制終了させる。

## 2. ペナルティ起因の幻覚 (Penalty-induced Hallucination)

**現象:**
突然、キャラ設定にない変な言葉遣い（今回なら「あたい」）や、支離滅裂な文章を話し出す。

**原因:**

* **禁止ワードの回避**: `repeat_penalty`（繰り返しペナルティ）を強くしすぎた結果、普段の一人称「私」や「ましろ」が**「使いすぎワード」として減点**されます。
* **苦し紛れの類語選択**: 「私」と言いたいのに言えないAIは、辞書の中から**「まだ使っていない、似た意味の言葉」**を探し出します。その結果、「あたい」「拙者」「わらわ」などの突飛な単語が選ばれます。

**今回のケース:**

> User: 「なんで一人称があたいになったの？」
> AI: （「ましろ」と言いたいがペナルティで言えない...代わりの言葉は...）→「あたい」

## 3. 論理崩壊 (Logic Collapse)

**現象:**
ユーザーの指摘（「噛んだ？」「間違ってるよ」）に対し、意味不明な言い訳を重ねて自滅する。

**原因:**

* **客観視の欠如**: AIには「言い訳をやめて黙る」というメタ認知がありません。
* **文脈の汚染**: ユーザーの「思考は丸見え」等のメタな指摘を、AIは「そういう劇のセリフ」として処理しようとします。その結果、物語の整合性が取れなくなり、支離滅裂な回答になります。
